# BLACKROOM Countdown

سیستم شمارش معکوس دو پنجره‌ای برای اتاق فرار / بلک‌روم: یک مانیتور برای بازیکن‌ها (`display`) و یکی برای اپراتور (`control`).

## اجرا

1. در ریشه پروژه: `python serve.py`
2. بروید به `http://127.0.0.1:8765/` و **باز کردن نمایش و کنترل** را بزنید.
3. پنجره نمایش را به مانیتور بازیکن بکشید و `F` بزنید تا تمام‌صفحه شود.
4. یک بار روی نمایش کلیک کنید تا صدا فعال شود.
5. صفحه لانچر را باز نگه دارید؛ پیوند دو پنجره از آن می‌گذرد.

سرور محلی علاوه بر فایل‌ها، TTS فارسی (`SAY`) و پروکسی دوربین داهوا (`/api/cam.mjpg`) را هم سرو می‌کند. تنظیمات دوربین در `camera.json` است.

## بک‌گراند تایمر (غار + ضربان)

فایل‌های فعلی در `audio/`:

- `sounds.mp3` / `cave-2.mp3` / `cave-3.mp3` → غار
- `slow.mp3` / `fast.mp3` → ضربان قلب کند / تند

غار و ضربان همزمان پخش می‌شوند. قطع یا تعویض با فید نرم (ولوم پایین می‌آید بعد قطع می‌شود).

## کاور تصویر

عکس را با **CHOOSE** انتخاب کنید یا در `images/` بگذارید و در `images/images.js` معرفی کنید. کاور کم‌رنگ زیر کل صفحه و هیرو می‌آید؛ **CLEAR** پاکش می‌کند.

## متن قبل از تایمر

1. متن را در **MSG / OVERLAY** بنویسید و **DISPLAY** بزنید
2. با **TIMER OFF** شمارش معکوس مخفی می‌شود و همان متن بزرگ و بالاتر روی صفحه می‌آید
3. با **TIMER ON** تایمر برمی‌گردد و متن دوباره زیر ساعت کوچک می‌شود

## اسپیک (Talkback)

**SPEAK** فقط تالک‌بک است (میکروفون → اسپیکر) و به بک‌گراند غار ربطی ندارد.

- اجازه میک روی پنجره کنترل گرفته می‌شود
- خروجی پیش‌فرض ویندوز را روی اسپیکر / HDMI بازیکن بگذارید
- هدست اپراتور برای جلوگیری از فیدبک بهتر است

## ساختار

```
index.html      لانچر و رله پیام‌ها
display.html    نمایش بازیکن + صدا
control.html    پنل اپراتور
audio/          ساندافکت‌ها + sounds.json
js/             منطق شمارش، لینک، صدا
css/            استایل نمایش و کنترل
```

## کنترل سریع

| عمل | محل |
| --- | --- |
| Start / Hold / Resume | TRANSPORT یا Space |
| Penalty / Trim | PENALTY و CLK TRIM |
| Volume تیک‌ها | AUDIO |
| Pulse heartbeat | PULSE |
| Overlay متن | MSG / OVERLAY |
| مخفی/نمایش تایمر | TIMER ON/OFF |
| بک‌گراند غار | TIMER BED |
| میکروفون → اسپیکر | SPEAK |
