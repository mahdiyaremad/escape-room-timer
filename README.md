# BLACKROOM Countdown

سیستم شمارش معکوس سرور‌بیس برای اتاق فرار / بلک‌روم: یک مانیتور **Display** (سورس بازیکن + صدا + دوربین روی صفحه) و یک یا چند **Control** از گوشی / سیستم‌های دیگر.

## اجرا

1. در ریشه پروژه: `python serve.py`
2. روی سیستم مانیتور بازیکن بروید به `http://127.0.0.1:8765/` یا IP لان همان سیستم
3. **Display** را باز کنید، به مانیتور بازیکن بکشید، `F` تمام‌صفحه، یک کلیک برای فعال‌سازی صدا
4. از گوشی یا سیستم اپراتور همان IP را باز کنید و وارد `control.html` شوید
5. پین ادمین پیش‌فرض: `blackroom` (در `room.json` عوض کنید)

سرور روی `0.0.0.0` گوش می‌دهد. همگام‌سازی دو مسیره است:

1. **LAN / IP محلی:** WebSocket روی `ws://IP:8765/ws`
2. **اینترنت عمومی:** فقط `https://ntfy.mred.ir` (بدون fallback). اگر این آدرس در دسترس نباشد، ریموت وصل نمی‌شود و وضعیت روی پنل «ناموفق» می‌ماند.

اگر LAN قطع باشد ولی ntfy در دسترس باشد، وضعیت اتاق از جمله زمان باقی‌مانده از ساعت سرور روی همان تاپیک سینک می‌شود. راهنمای کامل در `USAGE.md` است.

- تاپیک = رمز کانال (`ntfy.topic`)
- `ntfy.token` می‌تواند `tk_...` (Bearer) یا `user:pass` (Basic) باشد
- از Control دکمه **REMOTE HTML** را بزن و فایل را روی گوشی باز کن (کنترل از اینترنت موبایل فقط با ntfy). دوربین زنده / SPEAK / آپلود کاور فقط روی پنل LAN هستند؛ روشن‌کردن دوربین روی Display از ریموت ممکن است.

## نقش‌ها

| نقش | صفحه | کار |
| --- | --- | --- |
| Source / Display | `display.html` | تایمر، صدا، کاور، نمایش دوربین |
| Admin / Control | `control.html` | مدیریت تایمر، ساندبار، SFX، دوربین، پیام |

چند Control همزمان مجاز است؛ آخرین `revision` برنده‌ی وضعیت اتاق است.

## صداها

فایل‌های `audio/`:

- غار / فضا: `sounds.mp3`, `cave-2.mp3`, `cave-3.mp3`, `horror-amb.mp3`, `dread.mp3`
- ضربان: `slow.mp3`, `fast.mp3`
- پد / ترسناک: `scream.mp3`, `break.mp3`, `chainsaw.mp3`, `jumpscare.mp3`, `whisper.mp3`, `creak.mp3`, `wail.mp3`

غار و ضربان همزمان پخش می‌شوند. پدها one-shot هستند.

## دوربین

پروکسی داهوا از سرور (`/api/cam.mjpg`). تنظیمات در `camera.json`. مانیتور Display فقط دستور `camera` را از کنترل می‌گیرد؛ استریم از همان سرور خوانده می‌شود.

## اسپیک (Talkback)

**SPEAK** میکروفون را روی همان دستگاه Control به خروجی پیش‌فرض ویندوز می‌فرستد. برای تالک‌بک واقعی، خروجی همان سیستمی باشد که به اسپیکر اتاق وصل است. از روی گوشی، SPEAK صدای گوشی را پخش می‌کند نه مانیتور Display.

## تنظیم اتاق

`room.json`:

```json
{
  "bind": "0.0.0.0",
  "port": 8765,
  "adminPin": "blackroom",
  "roomName": "BLACKROOM"
}
```

اگر `adminPin` خالی باشد، کنترل بدون پین باز است.

## ساختار

```
index.html      هاب + لینک‌های LAN
display.html    سورس مانیتور بازیکن
control.html    پنل ادمین
serve.py        استاتیک + room hub + TTS + دوربین
room.json       پین و bind
audio/          ساندافکت‌ها
js/             منطق شمارش و لینک سرور
```

## کنترل سریع

| عمل | محل |
| --- | --- |
| Start / Hold / Resume | TRANSPORT یا Space |
| Penalty / Trim | PENALTY و CLK TRIM |
| Volume تیک‌ها | AUDIO |
| SFX ترسناک / اره | PAD / TIMER BED |
| Overlay متن | MSG / OVERLAY |
| دوربین روی Display | CAMERA → ON DISPLAY |
